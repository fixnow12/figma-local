# figma-local

**figma-local — локальное подключение Figma Desktop к Codex и OpenCode.**

Вы описываете задачу обычными словами, а ассистент читает открытый макет и меняет нужные слои: тексты, размеры, отступы, цвета и компоненты.

> Создай рядом копию выделенного экрана. Замени заголовок на «Поддержать фонд» и сделай кнопку высотой 48 px. Оригинал не меняй.

## Как это работает

В проекте две части:

- **MCP-сервер** даёт ассистенту команды для работы с Figma.
- **Figma Desktop Bridge** — плагин, который выполняет эти команды в открытом файле Figma.

Вы работаете в чате, а результат появляется в Figma. Для подключения не нужен отдельный токен Figma. Окно Bridge должно оставаться открытым.

## Что можно делать

- Читать выделенные слои и получать скриншоты макета.
- Менять тексты, шрифты, цвета, размеры и отступы, настраивать Auto Layout.
- Копировать блоки, собирать экраны и вставлять доступные библиотечные компоненты.
- Подключать библиотечные переменные — например, цвета и размеры — и выбирать доступные режимы оформления.
- Работать с текстовыми списками, векторами и масштабом экземпляров компонентов.
- Добавлять ссылки и переходы между экранами.
- Экспортировать иконки и изображения, переключать страницы и задавать обложку файла.

## Что понадобится

- **macOS или Windows 10/11**.
- Установленное приложение **Figma Desktop**.
- **Codex или OpenCode** — достаточно одного из них.
- [Node.js 20 или новее](https://nodejs.org/) и [Git](https://git-scm.com/).
- Доступ к нужным файлам и библиотекам в Figma.

## Установка

### 1. Скачайте проект

Откройте Терминал на macOS или PowerShell на Windows и выполните:

```bash
git clone https://github.com/fixnow12/figma-local.git
cd figma-local
```

### 2. Запустите установщик

**macOS:**

```bash
bash scripts/install.sh
```

**Windows:**

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1
```

Установщик загрузит необходимые пакеты, запустит проверки и подготовит плагин. Дождитесь сообщения **«Готово»** и сохраните показанный путь к `manifest.json`.

### 3. Добавьте Bridge в Figma

В Figma Desktop выберите **Plugins → Development → Import plugin from manifest…** и откройте подготовленный `manifest.json`.

Обычно он находится здесь:

- macOS: `~/.figma-local-bridge/figma-plugin/manifest.json`. Чтобы вставить путь в окно выбора файла, нажмите `⌘⇧G`.
- Windows: `%USERPROFILE%\.figma-local-bridge\figma-plugin\manifest.json`.

Импорт нужен один раз. Используйте путь из установщика, а не `manifest.template.json` из исходников проекта.

### 4. Откройте ассистента

**Codex:** перезапустите приложение, откройте папку `figma-local` и создайте новую задачу.

<details>
<summary>Что делать, если установщик не нашёл Codex</summary>

Для автоматической установки команда `codex` должна быть доступна в терминале. Когда она станет доступна, выполните из папки проекта:

```bash
codex plugin marketplace add .
codex plugin add figma-local-bridge@figma-local
```

Затем перезапустите Codex и создайте новую задачу.

</details>

**OpenCode:** откройте папку `figma-local` и создайте новый чат. Настройки подключения уже есть в `opencode.json`.

## Фоновая работа

Для сборки со шрифтами откройте целевой файл в **отдельном окне Figma Desktop**, запустите в нём Bridge и оставьте окно несвёрнутым. После этого можно работать в другом окне. Команда меню вкладки: **Move to New Window** или **Move to Another Window → New Window**.

Скрытая вкладка в одном окне может зависать при первой загрузке шрифта. Перед записью агент проверяет реальную спецификацию через `render_screen` с `dryRun:true`. При тайм-ауте он сохраняет причину и просит изменить условия, а не повторяет запись. [Порядок проверки и восстановления для всех агентов](plugins/figma-local-bridge/skills/figma-local/references/background-fonts.md).

## Первый запрос

1. Откройте нужный файл в Figma Desktop.
2. Запустите **Plugins → Development → Figma Desktop Bridge — Auto**.
3. Оставьте плагин открытым и выделите экран или блок.
4. Напишите ассистенту:

> Прочитай выделение в Figma через figma-local и покажи скриншот.

Если на скриншоте нужный блок, подключение работает. Можно давать задания:

> Сделай отступы между карточками по 16 px.

> Проверь Auto Layout выделенного блока и исправь выравнивание.

> Сделай пункты оглавления ссылками на соответствующие экраны.

> Экспортируй выделенные иконки в SVG.

Для нескольких файлов запустите Bridge в каждом и укажите в запросе ссылку на нужный файл.

## Работа с дизайн-системой

Ассистент может использовать доступные вашему аккаунту компоненты и переменные библиотеки. Подключение переменной к слою не меняет её значение в исходной библиотеке. Полный поиск по всем внешним библиотекам не поддерживается.

Если важны библиотечные связи, укажите это в задаче:

> Используй исходные библиотечные компоненты и переменные. Не отсоединяй экземпляры и не заменяй их обычными слоями.

Правки оригиналов библиотечных компонентов согласовываются отдельно.

**Копирование и воссоздание — разные операции.** При копировании существующих блоков библиотечные связи сохраняются. Воссоздание по внешнему виду создаёт обычные слои и не сохраняет эти связи. Часть содержимого, например видеозаливки, не поддерживается. [Подробнее об ограничениях](plugins/figma-local-bridge/skills/figma-local/references/reconstruction.md).

## Если что-то не работает

- **Ассистент не видит файл:** проверьте, что Bridge открыт именно в нём, и попросите проверить подключение через `figma-local`.
- **В чате нет команд Figma:** повторите установку, перезапустите ассистента и создайте новую задачу или чат.
- **Запрос оборвался или завис:** сначала проверьте состояние операции и результат в Figma. Изменение могло выполниться — повторять его сразу не стоит.
- **Результат отличается от ожидаемого:** укажите конкретный блок и нужную правку. Проверка ассистента не заменяет ваш просмотр макета.

[Дополнительные проверки и восстановление соединения](docs/maintenance.md).

## Обновление

В папке проекта выполните:

```bash
git pull --ff-only
```

Затем повторите установку для своей ОС. Закройте Bridge и приложения, использующие это подключение, подождите минуту и откройте их снова. Создайте новую задачу или чат и проверьте выделение.

Если путь к `manifest.json` прежний, повторный импорт в Figma не нужен. Одного скачивания новых исходников недостаточно: установленную копию обновляет установщик.

## Данные и доступ

Bridge соединяется с ассистентом на вашем компьютере. Обработка данных моделью зависит от выбранного ассистента и его настроек: локальное подключение не означает, что модель работает офлайн.

Папка `.figma-local-bridge` в домашнем каталоге содержит ключи подключения — не пересылайте и не публикуйте её. Закрытие плагина отключает его доступ к файлу.

[Подробнее о подключении и безопасности](plugins/figma-local-bridge/AUTO_CONNECTION.md).
