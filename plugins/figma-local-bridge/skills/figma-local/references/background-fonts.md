# Фоновая работа и шрифты

Bridge обращается к точному `fileKey`, но загрузкой шрифтов управляет Figma Desktop. Неактивная вкладка внутри одного окна может отвечать на команды плагина и одновременно зависать на `loadFontAsync`.

Перед фоновой сборкой:

1. В контекстном меню вкладки целевого файла выберите **Move to New Window** или **Move to Another Window → New Window**. Оставьте это окно открытым, не сворачивайте его.
2. Запустите установленный Bridge в целевом файле. После этого можно работать в другом окне Figma.
3. Проверьте точный `get_status(fileKey)`, затем один `render_screen` с `dryRun:true`, `screenshot:false` и реальной спецификацией будущего слайда. Не используйте искусственный текст для прогрева.
4. Только после успешного ответа продолжайте запись. Во время операции не активируйте целевое окно для обхода зависания.

Эти шаги одинаковы для Codex, OpenCode и других клиентов типизированного CLI/MCP. Если агент не управляет окнами, он сообщает пользователю эти действия и ждёт фактического выполнения. Не отмечайте их выполненными по `isActive`: Plugin API не подтверждает расположение и видимость окна.

При `FONT_SERVICE_TIMEOUT` сохраните запрос, ответ и состояние подключения. Повтор неизменённого запроса после ожидания запрещён. После реального изменения условий (например, перенос в отдельное окно) допустима одна проверка той же спецификации. Если снова не сработало, сохраните блокер и проверьте доступность точного шрифта/службы; не заменяйте шрифт и не увеличивайте тайм-аут для получения формального успеха. Неизвестный результат записи сначала проверяется чтением; успешная проверка шрифтов не разрешает повторить запись вслепую.

Подтверждено 26 сентября 2026 на macOS, Figma Desktop 126.9.10, в двух новых файлах с Factor IO Regular/Bold: первая загрузка через настоящую спецификацию прошла при другом активном окне. Скрытая вкладка в одном окне до этого воспроизводила тайм-аут. Это проверенный обход в указанной конфигурации; другие версии и Windows требуют своей живой проверки. Внутренний глобальный кэш Figma не измеряется. Проверка шрифтов без записи не подтверждает PNG, импорт компонентов или клики Present.
